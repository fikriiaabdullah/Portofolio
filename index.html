Web app · AI

Kendali Proyek WIKA (PCP AI Agent)

A dashboard and chat for the Project Control & Planning team that answers questions about schedules, progress, constraints and vendors only from documents in the database, and always names the source file. If nothing matches, the model isn't called at all.

  • Reads Excel, PDF, PowerPoint, Word and MS Project XML. A 51 MB schedule parses in about 4 seconds.
  • Computes all 16 DCMA schedule-health criteria in Python; results match Oracle's assessment 16 of 16 on DPR II IKN and SMA Unggul Garuda Kaltara.
  • Turns Last Planner System reports into PPC and a constraint log, and plots weekly progress against the planned S-curve read from PDF.
  • Two-role approval: a new document doesn't feed the chat until an approver opens and accepts it.
  • Numbers are computed by code and handed to the model, never generated by it. Provider switches between Gemini and Claude by config, and the fallback is shown on screen.

FastAPI · SQLAlchemy · PostgreSQL · Alembic · Next.js 16 · React 19 · Tailwind v4 · shadcn/ui · Recharts · BM25 retrieval · Gemini API

Automation · Python

Monthly-report monitor (Lapbul INBD bot)

Every month, project sites upload six reports to SharePoint and the central team ticks them off in an Excel checklist by hand. The bot does the checking and the chasing.

  • Reads each project's SharePoint folder and compares it with the checklist, matching projects by code, not by name.
  • Writes V/X into a copy of the checklist, then reopens it and compares every cell (values, formulas, styles, comments, merged cells). Any change outside the plan and the copy is thrown away.
  • Builds next month's checklist sheet from the previous one.
  • Sends WhatsApp reminders only to projects that are still incomplete, on a staged schedule with escalation after the deadline.

Python · uv · openpyxl · pytest · SharePoint · WhatsApp
